# tizenbrew-kinowatch

TizenBrew site-mod module: opens https://kino.watch/ on a Samsung TV with simple remote-control navigation
(arrows move focus, OK clicks, Back goes back).

Add in TizenBrew module manager: `gh/AnoshkaAlexandr/-tizenbrew-kinowatch`

Unofficial, not affiliated with kino.watch. You sign in on the site itself; this module stores nothing.
